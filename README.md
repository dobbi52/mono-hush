# MONO HUSH

물을 밟으면 소리가 난다. 그것은 눈이 없고, 소리만 듣는다.

물에 잠긴 지하에서 열쇠 세 개를 찾아 문을 열고 나가는 흑백 도트 공포 게임이에요.
판자 위는 조용하지만 물속을 걸으면 물결이 퍼지고, 소리만 듣는 괴물이 그 소리를 따라와요.

## 하는 법

- 방마다 물 위에 놓인 **열쇠 3개**를 모아 맨 위의 문으로 나가요.
- 판자에서 판자로 **점프**해 건너요. 그냥 걸어 나가면 물에 빠져요.
- **돌**을 엉뚱한 곳에 던져 괴물을 유인하고, 괴물이 가까이 오면 **숨을 참아** 버텨요.
- 방은 다섯 개이고, 방마다 새 규칙이 하나씩 더해져요. 방 모양은 매판 바뀌어요.

## 조작

| | 휴대폰 | 컴퓨터 |
|---|---|---|
| 이동 | 화면을 끌기 (살짝 밀면 살금살금) | WASD / 방향키 (Shift: 살금살금) |
| 점프 | 점프 버튼 | Space |
| 돌 던지기 | 던지기 버튼을 끌어서 조준, 떼면 던지기 | 마우스로 조준, 클릭 |
| 숨 참기 | 숨 버튼을 누르는 동안 | Q를 누르는 동안 |

## 실행

`index.html` 하나로 돌아가요. 브라우저로 열면 바로 할 수 있어요. 소리를 켜면 더 무서워요.
